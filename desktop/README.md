# نسخه ویندوزی — سامانه پیشنهادات ارزیابی ریسک

این پوشه یک اپلیکیشن دسکتاپ **Electron** است که همان سامانه وب را در یک پنجره ویندوزی
اجرا می‌کند. کارکنان با نصب این برنامه روی کامپیوتر خود، بدون نیاز به باز کردن مرورگر،
پیشنهادات ریسک را ثبت می‌کنند و مدیر همان داده‌ها را در داشبورد می‌بیند.

---

## ساخت فایل اجرایی (`.exe`)

> ساخت فایل `.exe` باید روی ویندوز انجام شود. یک‌بار روی هر سیستم انجام می‌شود و
> خروجی آن قابل توزیع بین همه کارکنان است.

1. **Node.js** را نصب کنید (نسخه LTS): <https://nodejs.org>
2. فایل **`build-windows.bat`** را دوبار کلیک کنید.
3. پس از پایان، پوشه `release` به‌صورت خودکار باز می‌شود و دو فایل در آن ساخته شده است:

| فایل | کاربرد |
|---|---|
| `RiskSuggestions Setup 1.0.0.exe` | نصب‌کننده معمول ویندوز (میان‌بر روی دسکتاپ می‌سازد) |
| `RiskSuggestions-Portable-1.0.0.exe` | نسخه پرتابل؛ بدون نصب، فقط اجرا |

### اجرای آزمایشی بدون ساخت exe

```bat
npm install
npm start
```

---

## تنظیم آدرس سرور

برنامه به‌صورت پیش‌فرض به آدرس سامانه منتشرشده وصل می‌شود. برای تغییر آن:

- از منوی **فایل ← تنظیم آدرس سرور…** آدرس جدید را وارد کنید، یا
- متغیر محیطی `RISK_SERVER_URL` را قبل از اجرا تنظیم کنید.

آدرس ذخیره‌شده در مسیر زیر نگهداری می‌شود:

```
%APPDATA%\risk-desktop\config.json
```

اگر سرور در دسترس نباشد، برنامه صفحه «اتصال به سرور برقرار نشد» را با دکمه
«تلاش مجدد» نشان می‌دهد.

## ساختار فایل‌ها

```
desktop/
├── main.cjs            # فرآیند اصلی Electron: پنجره، منو، تنظیمات
├── preload.cjs         # پل امن بین صفحه تنظیمات و Electron
├── settings.html       # پنجره تنظیم آدرس سرور
├── icon.ico / icon.png # آیکون برنامه
├── package.json        # تنظیمات electron-builder
└── build-windows.bat   # ساخت یک‌کلیکی نسخه ویندوز
```

## نکات استقرار در سازمان

- **نصب روی چند کامپیوتر:** فایل `Setup.exe` را روی هر سیستم اجرا کنید. همه به یک
  سرور مرکزی وصل می‌شوند، بنابراین داده‌ها یکجا جمع می‌شوند.
- **کیوسک ثبت پیشنهاد:** برای سالن تولید می‌توانید یک سیستم با نسخه پرتابل و
  حالت تمام‌صفحه (منوی نمایش ← تمام‌صفحه) راه‌اندازی کنید.
- **به‌روزرسانی:** با تغییر آدرس سرور نیازی به نصب مجدد نیست؛ فقط آدرس را در
  تنظیمات عوض کنید.
